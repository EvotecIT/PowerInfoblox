Use PowerInfoblox when Infoblox IPAM, DNS, DHCP, or network data needs to be queried or changed from PowerShell.

The module wraps Infoblox REST API calls so scripts can connect once, inspect objects, and make controlled changes with PowerShell-native objects.

## Common tasks

- Connect to an Infoblox grid with explicit API settings.
- Query networks, network containers, DHCP ranges, DNS records, and schema details.
- Find next available IP addresses or networks.
- Apply controlled updates to DNS, DHCP, or IPAM objects.
