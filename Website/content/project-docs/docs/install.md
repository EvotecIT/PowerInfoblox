---

Install PowerInfoblox before trying the curated Infoblox examples.

```powershell
Install-Module -Name PowerInfoblox -Scope CurrentUser
Import-Module PowerInfoblox
```

PowerShell 7 generally provides clearer REST error details than Windows PowerShell 5.1.
